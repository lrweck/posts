Everything is a system, so I read about systems:

1. *The Design of Everyday Things* — affordances are everywhere
2. *Chaos Monkeys* — how the big platforms ship
3. *Site Reliability Engineering* — error budgets as a feature
4. *Clean Architecture* — the boundaries matter more than the framework
5. *A Philosophy of Software Design* — complexity you can see is fixable

Currently re-reading number five for the third time.
