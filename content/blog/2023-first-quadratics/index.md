I want to keep this blog as a mix of notes and long-form writing. Let's start with something small: the quadratic formula.

For any $ax^2 + bx + c = 0$:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

The discriminant $b^2 - 4ac$ tells you how many real roots exist. If it is positive you get two, zero gives one, negative means none — the classic.
